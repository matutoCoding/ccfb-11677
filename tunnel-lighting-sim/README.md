# 公路隧道照明仿真与驾驶视角预览系统

浏览器端隧道照明设计工具：参数化隧道建模、灯具布置、基于配光曲线的亮度计算、JTG 规范对照、眩光 TI 评估与第一人称驾驶暗适应模拟。纯前端 TypeScript + React + three.js，数据保存在本机浏览器，无需后端。

## 技术栈

- Vite + React 18 + TypeScript（strict 模式）
- three.js 0.169（隧道三维建模、第一人称驾驶渲染）
- Zustand + persist（localStorage 本地持久化）
- Recharts（亮度/TI 曲线）、Canvas（路面伪彩图）
- Vitest（光度学精度单元测试与端到端集成测试）

## 启动

```bash
npm install
npm run dev        # 开发服务器（默认 http://127.0.0.1:5180）
npm run build      # 类型检查 + 生产构建到 dist/
npm run test       # 运行全部测试（16 项）
```

## 计算方法（精度核心）

### 单灯点照度 — 平方反比余弦定律

```
E = I(γ, C) · cosθ / d²
```

- `I(γ,C)`：由灯具 C-γ 配光表双线性插值（C 向 360° 周期处理），单位 cd/1000lm，按额定光通量、维护系数 MF、调光系数换算
- `γ`：光线与灯具光轴夹角，由灯具安装姿态（yaw/tilt/roll，Rodrigues 旋转）与世界坐标几何求出
- `θ`：光线与表面法线夹角
- 路面亮度 `L = E·q0`；墙面漫反射亮度 `L = E·ρ/π`

### 眩光阈值增量 TI（CIE 88 / CIE 140）

```
Lv = 10 · Σ(Eθᵢ / θᵢ²)        θ 取 1.5°~60°，Eθ 为垂直视线平面照度
TI(%) = 65 · Lv / L̄av^0.8
```

### 规范对照（JTG/T D70/2-01-2014）

- 入口段 `Lth1 = k · L20(S)`，k 按设计车速查表（可在设置页覆盖）
- TH2 = 0.5·Lth1；TR1/TR2/TR3 = 0.15/0.05/0.02·Lth1
- 中间段 Lin 按车速与交通量查表；出口段 = 3×/1.5× Lin
- U0/U1 仅在**车道范围**内按区段考核（不含检修道路缘点）

### 视觉适应模型（驾驶预览）

一阶惯性环节：`dL_adapt/dt = (L_env − L_adapt)/τ`，渲染曝光 `∝ 1/L_adapt`。
车辆进洞瞬间适应亮度仍为洞外 L20 水平，洞内路面相对极暗即呈现黑洞效应。

## 精度验证

`tests/photometry.test.ts` 对朗伯测试灯做独立手算核对：

- 正下方、斜射、横向/纵向、tilt 姿态等几何，照度与手算公式相对误差 **< 0.01%**（验收线 1%）
- 配光表表点取值、C 角周期性、截止角、MF/调光线性、光通量比例
- 内置灯具配光按 `Φ = 2π∫I sinγ dγ` 数值积分归一化，误差 < 2%
- `tests/integration.test.ts`：端到端建模→布灯→网格计算→规范对照、多灯线性叠加、弯坡坐标正交性

## 目录结构

```
src/
  engine/          # 纯计算引擎（无 UI 依赖，可独立测试）
    geometry.ts      平纵线形/断面坐标变换
    photometry.ts    配光插值 + 平方反比余弦点照度
    luminaireLibrary.ts  内置灯具（归一化配光）
    iesParser.ts     IES LM-63 导入
    layout.ts        区段批量布灯
    standards.ts     JTG 规范表与区段生成
    calculation.ts   网格照度/亮度、U0/U1、TI
    report.ts        CSV 报告
  components/      # three.js 查看器、通用 UI、错误边界
  pages/           # 六个页面
  store/           # Zustand 持久化
tests/             # Vitest 精度与集成测试
```

## 已知边界

- 路面亮度采用平均亮度系数 q0 简化模型，未实现完整 R 表（r-table）逐方向反射；墙面按理想漫反射（朗伯）处理
- 未计入灯具间相互反射与多次反射光通
- IES 解析器支持常见 TILT=NONE 的 Type C 文件，复杂 TILT 几何不支持
